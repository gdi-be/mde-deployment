## Vorschaubild

#### Erläuterung
Das Vorschaubild sollte einen Kartenausschnitt oder ein Schaubild zeigen, das den Datenbestand anschaulich charakterisiert. Wählen Sie möglichst ein Motiv, das sich klar von den Vorschaubildern anderer Datenbestände unterscheidet.

#### Hinweise
* Senden Sie eine Bilddatei per Email an die Redaktion
* Übermitteln Sie ein quadratisches Bild mit einer Mindestgröße von 380 x 380 Pixeln
* Verzichten Sie beim Erstellen von Schaubildern auf Text im Bild.
